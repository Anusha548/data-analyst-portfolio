# Week 3 — Relational Databases and SQL Query Foundations

## Overview

This project documents my Week 3 Data Analyst roadmap practice using SQLite and DB Browser for SQLite. I practiced querying a sales dataset, sorting and filtering records, creating calculated expressions, handling NULL values, inspecting data types, and validating query results.

## Tools Used

- SQLite
- DB Browser for SQLite
- Microsoft Excel
- GitHub

## Topics Practiced

- SELECT and FROM
- Column aliases, DISTINCT, and LIMIT
- ORDER BY and sorting on multiple columns
- Arithmetic expressions and operator precedence
- WHERE and comparison operators
- AND, OR, NOT, IN, and BETWEEN
- LIKE and wildcard patterns
- IS NULL and IS NOT NULL
- SQLite storage types and CAST
- SQL syntax-error correction
- Query validation and data documentation

## Project Files

- `week3_single_table_queries.sql` — 25 single-table SQL practice queries
- `data_dictionary.md` — Dataset overview, column meanings, data types, and assumptions

## Dataset

The practice dataset contains sales-related columns: Order_ID, Order_Date, Customer, Region, Product, Category, Sales, Profit, and Quantity.

The expected dataset size is six data rows and nine columns. The source data should remain unchanged.

## Validation

Queries were designed to be checked against the original Excel data. Validation includes row counts, totals, sorting, filtering, and type inspection.

Results should be marked as validated only after they have been executed and compared with the source data.

## Learning Outcome

This practice helped me understand how to retrieve relevant data with SQL, apply conditions, sort results, create calculated outputs, recognize missing values, inspect types, and document assumptions.
